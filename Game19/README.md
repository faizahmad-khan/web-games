# Skyline Sprint

Skyline Sprint is a quick reflex browser game where you dodge incoming traffic blocks and try to survive as long as possible.

## Features

- Single-player arcade gameplay
- Keyboard and touch controls
- Speed curve that increases with score
- Local best-score persistence with localStorage
- No dependencies or build tools

## How To Play

1. Open index.html in your browser.
2. Click Start Run.
3. Move left and right to dodge blocks.
4. Press P to pause or resume.
5. Beat your best score.

## Controls

- Left movement: Left Arrow or A
- Right movement: Right Arrow or D
- Pause: P
- Mobile: Use the on-screen Left and Right buttons

## Files

- index.html: Markup and game UI
- style.css: Layout, visual style, and responsive design
- script.js: Game loop, controls, collision logic, and scoring

## Tech Stack

- HTML5 Canvas
- CSS3
- Vanilla JavaScript
