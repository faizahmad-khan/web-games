## 🎮 How to Play

### 🚀 Getting Started

1. **Game Setup**
   - Open `index.html` in your web browser
   - Choose the number of players (2-4)
   - Click "Next" to proceed

2. **Player Customization**
   - Enter custom names for each player (optional)
   - Select your preferred color from 8 vibrant options
   - Colors are pre-selected for quick start
   - Click "Start Game" when ready

3. **Using Controls**
   - 🌙 **Dark Mode Toggle** - Switch between light and dark themes
   - 🔊 **Sound Toggle** - Mute/unmute sound effects
   - Both controls are accessible anytime during gameplay

### 🎲 Game Rules

1. **Getting Started**
   - Each player starts locked and must roll **1** to unlock
   - Once unlocked, players can move freely on the board
   - Rolling 1 to unlock grants an extra turn!

2. **Taking Turns**
   - Click the "🎲 Roll Dice" button when it's your turn
   - Your piece moves automatically to the new position
   - The active player is highlighted with a golden glow

3. **Special Tiles**
   - 🐍 **Snake Head** - Slides you down to the snake's tail
   - 🪜 **Ladder Bottom** - Climbs you up to the ladder's top
   - ⭐🛡️⚡ **Power-up Tiles** - Collect special abilities

4. **Winning**
   - First player to reach exactly square **100** wins! 🏆
   - Need exact roll to land on 100 (no overshooting)
   - Winner is celebrated with confetti and statistics

### 🎯 Power-ups System

Power-ups add strategic depth to the classic gameplay:

#### ⭐ **Extra Turn**
- Automatically grants an additional dice roll
- Used immediately after your current turn
- Great for making quick progress!

#### 🛡️ **Shield**
- Protects you from one snake bite
- Automatically activates when landing on a snake
- Saves your position - no sliding down!
- Consumed after one use

#### ⚡ **Speed Boost**
- Collect for strategic advantages
- Appears on special board positions
- Randomized each game for variety

**Collecting Power-ups:**
- Simply land on a power-up tile to collect it
- Power-ups are shown next to your player card
- Use them strategically to gain an advantage!

### 🎮 Controls & Buttons

- **🎲 Roll Dice** - Roll the dice for your turn
- **🔄 Reset Game** - Restart with same players
- **🚪 Exit Game** - Return to setup screen
- **🌙/☀️** - Toggle dark/light mode
- **🔊/🔇** - Toggle sound on/off

### 📊 Viewing Statistics

- Real-time stats shown in the sidebar:
  - Total rolls by all players
  - Total snake bites
  - Total ladder climbs  
  - Total power-ups collected
- Winner's screen shows individual player stats

## 🔧 Customization

The game is highly customizable! Here are some ways to personalize it:

### 🎨 Visual Customization

#### Colors and Themes (in `snake_ladder.css`)
```css
:root {
    --bg-gradient-start: #667eea;  /* Light mode background */
    --bg-gradient-end: #764ba2;
    --cell-even: #e8f5e9;          /* Board cell colors */
    --cell-odd: #fff9c4;
}
```

#### Board Appearance
- Modify cell colors for different themes
- Adjust cell size by changing `cellSize` variable
- Customize snake and ladder colors
- Change animation durations and effects

### 🎮 Gameplay Customization (in `snake_ladder.js`)

#### Snake Positions
```javascript
const snakes = {
    16: 6,    // Add or modify snake positions
    47: 26,   // Format: start: end
    // Add more snakes...
};
```

#### Ladder Positions
```javascript
const ladders = {
    1: 38,    // Add or modify ladder positions
    4: 14,    // Format: start: end
    // Add more ladders...
};
```

#### Power-up Configuration
```javascript
// In initializePowerUps() function
const powerUpPositions = [13, 27, 45, 68, 82];  // Change positions
// Modify power-up types in powerUpTypes object
```

#### Game Settings
- Change number of players (min/max)
- Adjust board size (currently 100 squares)
- Modify unlock mechanism
- Change victory conditions
- Adjust animation speeds

### 🔊 Sound Customization
```javascript
// In soundEffects object, modify frequencies and durations
diceRoll: () => playTone(200, 50),  // frequency, duration
snake: () => playTone(100, 200, 'sawtooth'),  // add waveform type
```

### 🎨 Available Player Colors
Add more colors to the `availableColors` array:
```javascript
{ name: 'ColorName', color: '#hexcode' }
```

### 📏 Responsive Breakpoints
Adjust in CSS for different device sizes:
```css
@media (max-width: 768px) { /* Tablet */ }
@media (max-width: 480px) { /* Mobile */ }
```

## ❓ FAQ

### General Questions

**Q: Do I need an internet connection to play?**  
A: No! After loading the game once, it works completely offline.

**Q: How many players can play?**  
A: 2-4 players can play in one game.

**Q: Can I play alone?**  
A: The minimum is 2 players, but you can control both players yourself!

### Gameplay Questions

**Q: How do I unlock my player?**  
A: Roll the dice until you get a 1. This unlocks your player and gives you an extra turn!

**Q: What happens if I can't reach exactly 100?**  
A: If your roll would take you past 100, you stay in place and it becomes the next player's turn.

**Q: Can I save my game progress?**  
A: Currently, the game doesn't have a save feature. Each game is played in one session.

**Q: How do power-ups work?**  
A: Land on a power-up tile to collect it. It appears next to your name and activates automatically when needed (Shield) or after your turn (Extra Turn).

### Technical Questions

**Q: Which browsers are supported?**  
A: All modern browsers including Chrome, Firefox, Safari, and Edge. Mobile browsers are also fully supported.

**Q: Why isn't sound working?**  
A: Some browsers block autoplay audio. Click anywhere on the page first, or check if the sound is muted (🔇 button).

**Q: Can I customize the game?**  
A: Yes! See the [Customization](#-customization) section for details on modifying colors, positions, and game rules.

**Q: Is the game mobile-friendly?**  
A: Absolutely! The game is fully responsive and works great on phones and tablets.

**Q: Can I contribute to the project?**  
A: Yes! Check the [Contributing](#-contributing) section for guidelines.

## 🎯 Tips & Strategies

### 🎲 General Tips
- **Rolling 1 is crucial** at the start - it unlocks you AND gives an extra turn!
- **Power-ups are strategic** - collect them early for better chances
- **Shields are valuable** near the top where snakes are deadlier
- **Extra turns** can help you reach the goal faster

### 🛡️ Power-up Strategy
- **Shield:** Save it for when you're high on the board (snakes hurt more there)
- **Extra Turn:** Great for momentum - use when on a hot streak
- **Collect early:** Power-ups on lower squares are easier to reach

### 🎮 Advanced Play
- Plan your moves around power-up positions
- Watch for snake positions to avoid (or prepare shields)
- Ladder positions are your friends - aim for them!
- The big ladder at 28→84 is a game-changer
